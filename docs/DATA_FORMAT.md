# CSVの形式（管理ページの「CSV」ボタンで出力されるもの）

文字コードは UTF-8（BOM付き・Excelでそのまま開ける）、1行目が列名です。1行が1件の記録です。

| 列名 | 型 | 内容 | 例 |
|---|---|---|---|
| `id` | 文字列（UUID） | 記録ごとの一意なID。重複登録の判定に使える | `d794291a-e974-...` |
| `user` | 文字列 | 記録したメンバーの名前（ローマ字） | `takumi` |
| `datetime_local` | 日時（ISO 8601・タイムゾーン付き） | 「記録する」を押した瞬間（ミリ秒まで） | `2026-10-14T00:49:22.295+09:00` |
| `epoch_ms` | 整数 | 同じ時刻のUNIXミリ秒 | `1791906562295` |
| `age` | 文字列 | 年齢層：`15-18` / `19-22` / `23-34` / `35-64` / `65+` | `19-22` |
| `group` | 文字列 | グループのコード（下の表） | `GG` |
| `group_label` | 文字列 | グループの日本語名 | `女の子のグループ` |
| `gender` | 文字列 | グループから自動：`F` / `M` / 空欄 | `F` |
| `count_min` | 整数 | 人数の最小（1〜30） | `3` |
| `count_max` | 整数 | 人数の最大（1〜30）。ちょうどの場合は `count_min` と同じ | `5` |
| `note` | 文字列 | 定型文「誰、どこ、何してる、感情」をそのまま（空欄あり） | `ヤンキー、マクドナルド前、タバコ吸う、臭い嫌だ` |
| `who` | 文字列 | 定型文の「誰」（観察対象の特徴。空欄あり） | `ヤンキー` |
| `place` | 文字列 | 定型文の「どこ」 | `マクドナルド前` |
| `action` | 文字列 | 定型文の「何してる」 | `タバコ吸う` |
| `feeling` | 文字列 | 定型文の「自分の感情」 | `臭い嫌だ` |
| `device_lat` / `device_lng` | 小数 | スマホの位置情報（オンにした場合のみ） | `35.787` |
| `device_acc_m` | 小数 | 位置情報の誤差（メートル） | `12` |
| `gpx_lat` / `gpx_lng` | 小数 | ルートヒストリーのGPXと照合した位置 | `35.7870530` |
| `gpx_diff_sec` | 小数 | 照合に使ったGPX地点との時間差（秒） | `4.7` |
| `gpx_file` | 文字列 | 照合に使ったGPXファイル名 | `takumi.gpx` |
| `server_time` | 日時 | サーバーが受け取った時刻 | `2026-10-14T00:49:22.306+09:00` |

## グループのコード

| コード | 意味 |
|---|---|
| `CP` | カップル |
| `FM` | 家族 |
| `GG` | 女の子のグループ（入力ボタンは「女の子」・2人以上） |
| `BG` | 男の子のグループ（入力ボタンは「男の子」・2人以上） |
| `XG` | 男女混合グループ（入力ボタンは「男女」） |
| `MX` | 年齢差のあるグループ |
| `G` | 女の子1人（人数1人で「女の子」を選んだとき自動） |
| `B` | 男の子1人（人数1人で「男の子」を選んだとき自動） |

## 軌跡（管理ページの「軌跡GPX」ボタン）
アプリの「軌跡の記録」で記録したルートは、GPX（GPS軌跡の標準形式）で書き出せます。
1本の軌跡が1つの `<trk>` になり、名前は「メンバー名 開始時刻」です。各地点に緯度・経度・時刻（UTC）が入ります。

## 補足
- 定型文は入力時に「、」「。」「,」「.」を取り除いて保存するので、`note` を「、」で区切ると必ず4つに分かれます（古い自由記述のメモは `who`〜`feeling` が空欄になります）。
- 位置は `gpx_lat/gpx_lng` があればそれを優先し、なければ `device_lat/device_lng` を使うのがおすすめです。
- `user` と `group` はPostgreSQL（Supabase）の予約語なので、テーブルの列名にするときは `"user"` `"group"` のようにダブルクォートで囲む必要があります。`supabase/schema.sql` に例があります。
